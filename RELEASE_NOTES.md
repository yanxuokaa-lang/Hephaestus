# Release Notes

## v0.1.0

This first public snapshot publishes the stable core-code surface for Hephaestus:

- source owners across `tool`, `atom`, `skill`, and `task`
- a deterministic simulation seam for inspection and local testing
- the public proof-case contract used for the Phase 1C tabletop scenario
- lightweight CLI commands for listing the public bundle contents

The repository intentionally focuses on stable source and architecture. Runtime recordings,
process records, and private working materials are outside this snapshot.
