# Phase 1C Public Snapshot

This repository packages the stable source contracts that define the public Phase 1C tabletop
scenario:

- scene-carrier truth for category-to-zone organization
- proof-case contracts for ordered tabletop tasks
- deterministic simulation and safety boundaries
- reusable grasp and place policies

The public snapshot is source-first. Recordings and richer runtime captures can be produced
outside this repository when needed.
